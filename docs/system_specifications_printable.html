7. SYSTEM SPECIFICATIONS

7.1 HARDWARE REQUIREMENTS

The RecruitSmart CRM system is designed to run on modern computing environments that can handle concurrent processing of AI models and web services. Below are the minimum and recommended hardware specifications.

Development Workstation:

  • Processor: Intel Core i5/AMD Ryzen 5 (Minimum); Intel Core i7/AMD Ryzen 7 11th Gen+ (Recommended).
  • Memory: 8GB RAM (Minimum); 16GB DDR4/DDR5 RAM (Recommended) for local AI testing and multi-service development.
  • Storage: 256GB SSD (Minimum); 512GB NVMe SSD for fast compilation and Docker container performance.
  • Network: Stable broadband connection for API integration with Google Gemini services.

Target Server (Deployment):

  • Cloud Provider: Render / AWS / Railway.
  • RAM: 1GB to 2GB dynamic allocation.
  • vCPU: 1 - 2 vCPUs for standard request handling.

7.2 SOFTWARE REQUIREMENTS

The application follows a modern full-stack architecture using Java for the backend and React for the frontend ecosystem.

Backend Technologies:

  • Language: Java 17 LTS (Standard compatibility).
  • Framework: Spring Boot 3.4.1 (API Gateway, Security, and ORM).
  • Build Tool: Maven 3.9+ for dependency management.
  • AI Engine: Google Gemini 1.5 Flash API (Streaming Interface).

Frontend Technologies:

  • Web Framework: React 18.2.0 with Vite (Build system).
  • Mobile Bridge: Capacitor 8.3.0 for Android/iOS builds.
  • Styling: Vanilla CSS with Modern Flexbox and Grid.

7.3 EXECUTION OF WEB FRONT-END

To execute the web frontend in a local development environment, follow these steps:

  1. Install Dependencies: Navigate to the /frontend directory and run npm install.
  2. Configure Environment: Create a .env file with the VITE_API_URL pointing to the backend service.
  3. Start Development Server: Execute npm run dev. The interface will be accessible at http://localhost:5173.
  4. Build for Production: Run npm run build to generate the optimized /dist folder.

7.4 EXECUTION OF ANDROID FRONT-END

The mobile application is generated from the React codebase using Capacitor. The execution workflow is as follows:

  1. Build Web Assets: Run npm run build in the frontend folder.
  2. Sync Capacitor: Execute npx cap sync android to transfer assets to the Android platform.
  3. Open Android Studio: Run npx cap open android to open the native project.
  4. Deploy on Device: Build and run the project on a connected physical device or emulator with API Level 26+.
